# Backup and restore guide

LifeOS includes a JSON backup/export and restore feature in its interface. A backup is useful when you want a separate copy before a reset or browser cleanup.

## Before backing up

- Export the current data from the app's available backup control.
- Save the JSON file somewhere you control.
- Treat the file as private because it may contain your personal tasks, notes, journal entries, and finance records.

## Before restoring

- Make a fresh backup of the current state first.
- Choose a backup file created by LifeOS.
- Review the restored dashboard and key sections.

## Remember

A backup file is not encrypted by LifeOS. Keep it in a trusted location and do not upload it to a public repository. Browser-local storage is not a substitute for a reliable backup.
