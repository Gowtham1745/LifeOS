# Contributing to LifeOS

Thanks for helping LifeOS become more useful, one small improvement at a time.

## Suggested workflow

1. Pick one user-visible problem or maintenance task.
2. Keep the change focused and explain why it helps.
3. Run the production build with `cd frontend`, `npm ci`, and `npm run build`.
4. Review the changed files and avoid committing credentials, local databases, build output, or dependencies.
5. Use a descriptive commit message, such as `Improve mobile dashboard spacing`.
6. Check the CI and deployment results after pushing.

## Good first contributions

- Improve empty-state guidance.
- Fix a date or streak edge case.
- Add keyboard and screen-reader support.
- Improve a small-screen layout.
- Add a test or clarify documentation.

Do not add empty commits or repeated no-op changes just to increase a contribution graph. Real, reviewable progress is more valuable.
