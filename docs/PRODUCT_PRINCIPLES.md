# LifeOS product principles

## Calm by default

Use clear hierarchy, whitespace, restrained color, and useful summaries. Avoid adding decoration that competes with the user's next action.

## Small actions first

The most common actions—adding a task, checking a habit, and reviewing a goal—should be quick and predictable.

## Honest privacy

The current GitHub Pages edition stores data in the current browser. Do not imply that the data is backed up or synchronized across devices.

## Responsive everywhere

Design for narrow phones first, then expand naturally for tablets, laptops, monitors, and large screens. Avoid fixed widths that force horizontal scrolling.

## Accessible interaction

Controls should have meaningful labels, visible keyboard focus, and touch-friendly sizes. Honor reduced-motion preferences.

## Ship carefully

Prefer a small, tested change over a large rewrite. Explain the user benefit in each commit and verify the deployed result.
