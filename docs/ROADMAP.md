# LifeOS roadmap

LifeOS is developed in small, reviewable steps. The aim is a calm and accessible daily companion, not a dashboard overloaded with features.

## Near-term priorities

- [x] Local-first profile and onboarding
- [x] Tasks, habits, goals, finance, notes, journal, focus, and calendar sections
- [x] Responsive dashboard and theme switching
- [ ] Validate empty states and form input across every section
- [ ] Add focused automated tests for date and streak calculations
- [ ] Improve keyboard navigation and accessible labels
- [ ] Add a user-controlled backup/restore walkthrough
- [ ] Evaluate an optional hosted sync service only after its privacy and security design is ready

## Product principles

1. Keep daily actions quick.
2. Never imply data is cloud-synced when it is only stored locally.
3. Prefer understandable defaults and reversible actions.
4. Keep phone, tablet, and desktop layouts readable.
5. Test each behavior before shipping it.
